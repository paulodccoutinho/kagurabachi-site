# ⚔️ Kagurabachi — Site Informativo

## 📖 Sobre o projeto

Este projeto consiste no desenvolvimento de um site informativo dedicado ao mangá **Kagurabachi**.

O site está sendo desenvolvido de forma gradual, aplicando conceitos fundamentais de **HTML, CSS e JavaScript**, com foco em organização do código, responsividade, interatividade e experiência do usuário.

O projeto também serve como atividade prática para acompanhar a evolução do aprendizado em desenvolvimento web.

---

## 🎯 Objetivos

* Criar uma página web temática sobre Kagurabachi.
* Praticar a estruturação de páginas utilizando HTML5.
* Desenvolver uma identidade visual utilizando CSS3.
* Tornar a página responsiva para diferentes tamanhos de tela.
* Implementar funcionalidades interativas com JavaScript.
* Criar cards interativos para os personagens.
* Desenvolver um menu de navegação adaptado para dispositivos móveis.
* Organizar o projeto seguindo uma estrutura de arquivos adequada.
* Aplicar boas práticas de desenvolvimento web.

---

## 🛠️ Tecnologias utilizadas

O projeto utiliza as seguintes tecnologias:

* **HTML5** — estrutura e organização do conteúdo.
* **CSS3** — estilização, layout, responsividade e efeitos visuais.
* **JavaScript** — funcionalidades e interações da página.
* **Visual Studio Code** — editor utilizado no desenvolvimento.

## 📱 Responsividade

O projeto foi desenvolvido pensando em diferentes tamanhos de tela.

São utilizados **Media Queries** para adaptar o layout para:

* 🖥️ Computadores;
* 💻 Notebooks;
* 📱 Tablets;
* 📱 Celulares.

Em telas menores, o menu de navegação é substituído por um botão de menu mobile.

---

## ⚔️ Funcionalidades

### Menu de navegação

O site possui um menu principal para facilitar a navegação entre as diferentes seções da página.

Em dispositivos móveis, o menu pode ser aberto através do botão **☰**.

### 👤 Cards de personagens

Os personagens são apresentados através de cards.

O projeto utiliza JavaScript para permitir uma interação em que informações adicionais podem ser exibidas ou ocultadas.

### 🔎 Filtros

A seção de personagens possui filtros que permitem organizar ou selecionar personagens de acordo com os critérios definidos no projeto.

### ⚡ Efeitos visuais

Foram utilizados efeitos de transição e `hover` para melhorar a interação do usuário com:

* Cards;
* Botões;
* Links;
* Elementos de navegação.
